## Answer for the actual applications

1. **Standalone proximal Gibbs application of the new family:** no NEW hidden-center levels are needed. Every posterior call has the supplied numerical center Y_n=X_n+sqrt(a)G_n. The one completed CW7 seed call still contains its own fixed legacy R13/history implementation, and that complete bill remains inside the known seed; it is not erased or declared a cache. 2. **The selected fixed denominator-32 kinetic construction:** the external stage force depth is seven. It executes seven position substitutions and then evaluates the force at stage seven. Its already completed RAW7 and accurate VALUE8 libraries additionally contain their fixed five- and six-position-update inner histories, respectively, together with their expressly older source libraries. Those internal histories are part of each complete call's bill, not extra external depth silently omitted here.

3. **A growing-order version using the same outer reference architecture:** the external stage depth must grow with the desired order. After J substitutions that reference has local order h^(2J+3) and accumulated capacity 2J+2. To match a target H^(2R), that particular reference needs J>=ceil(R-1). Keeping J=7 cannot provide an unbounded-order outer theorem merely because the supplied posterior has higher order. This is a requirement of this reference/cost route, not a lower bound on other outer integrators.

The selected fixed construction's hidden stage depth does not grow with the number of outer phases or with log(1/a). Those quantities give separate actual call multiplicities. A varying phase input is supplied as a caller; the algorithm does not replay its whole earlier outer trajectory inside every new local force source.

## 2. What is replayed, and what is only a supplied caller

### New known-center family

One complete previous known-center K_P(a,y) is executed at the SAME requested heat a. Its actual internal seed work, source versions, zero computations and tape are charged. Its returned value can feed all new deterministic quarter nodes. The new original-gradient evaluations occur at their actual different path points and are not cached merely because they use the same potential.

The new family is defined recursively from its own previous known-center member, down to the chosen completed known CW7 seed. It does not replace each generation by a fresh call to the old expensive uniform hidden family. A finite proxy replay at a changed argument re-executes the complete old retained graph and its original nodes; the polynomial-logarithmic replay multiplier is included in the proxy bill.

### Existing uniform known/hidden upgrade

The old construction's new source/statistic uses complete **strictly older-generation** force/history providers at the requested stage depth. Each empirical or coefficient bank evaluates its own complete private old provider after the captured caller is fixed. Its old history, own hidden statistic, decoder children, private zero paths, and source/proxy aliases are part of that bank. They are not supplied scalar caller labels.

### Optional same-order depth-indexed hidden adapter

If one instead explicitly constructs hidden level j at the new order R from already completed level j-1, then the repeated provider is a complete **same-order, lower-depth** source. This is an acyclic depth construction, not a captured-value cache. Every empirical bank still pays that complete lower-depth source. This alternative must have its own level-by-level law/graph admission; it is not what the already published old-generation program does by default.

### Captured records

For a local phase, its entering physical state and the once-refreshed momentum G0 are fixed caller labels. They may be shared according to that source's actual interface. A later outer phase has a different caller and a fresh refresh, so this does not cache its stochastic force samples across phases.

Stored zero values are reusable only at an identical semantic key. A nested zero evaluated at a private decoder center remains private to that complete source occurrence. The complete E-bank copies cannot be reduced to one expensive sampled ancestor plus cheap terminal calls by moving that ancestor into the caller after the fact.

## 3. What a fixed-depth linear estimate would and would not mean

Suppose an independently admitted depth-indexed adapter has the stated weak-E cost at every level:

    Q_(R,j+1) <= Lambda_(R,j) [Q_known,R
                         + a^[-(R-5.4)]_+ Q_(R,j)],
    Q_(R,0)=Q_known,R.

Then the cost algebra gives

    k_(R,j) <= (R-3/2)+j(R-5.4)_+.

This is a conditional cost consequence, not a new hidden-family admission. At any specified depth j independent of R it is linear in R. If j grows like R-1, as it does for the natural growing-order outer-reference list above, this certificate is quadratic in R. The depth cannot be moved into a prefactor when it changes an a exponent.

For the fixed denominator-32 application, j=7 is a genuine fixed external count, but its accuracy capacity is also fixed at sixteen. Letting a supplied posterior order tend to infinity while holding that consumer fixed provides no unbounded-order sampling benefit. Its existing RAW7/A8 source/coefficient construction is already polynomial-logarithmic at its fixed grades; this audit does not claim that replacing those components by the new slower deterministic family improves its numerical query bound.

For the new ordinary proximal chain, j=0 at the application interface, and the standalone known-center bound is all that is required. Its explicit outer-step count and limiting dimension exponent 1/2 are given in Section 10 of the reviewed construction. That conclusion remains sound without any depth-indexed hidden extension.

## 4. Additional source contracts still matter

The depth count does not authorize substituting the new source for every old native coefficient port. The new reviewed program promises the specified weak J=2.9 protected proxy. An application asking for other strong marks, different physical frames or accurate-only versus RAW source returns must separately select and verify its matched finite version and widths.

Increasing outer order also needs its own coefficient/mean/covariance closure, incoming moments, domain and numerical census. The reference-depth formula alone is not an existence theorem for that growing-order outer algorithm.

The useful established separation is therefore:

- standalone known-center law/source family: independently reviewed linear query exponent;
- ordinary known-center-only outer consumer: completely explicit, no new hidden service;
- fixed old kinetic consumer: seven external hidden stage levels plus its already charged fixed child libraries;
- unbounded-order use of that same kinetic architecture: growing hidden depth and remaining mean/coefficient costs must be paid.
