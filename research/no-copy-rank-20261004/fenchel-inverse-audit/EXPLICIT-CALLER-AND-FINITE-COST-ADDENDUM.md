# Explicit caller and finite-query bill for the dual-completed lift

2026-10-04. This supplements equations (3)–(11) of `FENCHEL-INVERSE-LIFT-AND-LITERAL-K3-GRAPH-CURRENT.md`. It adds no new source or sampling claim.

Hold r,a,epsilon,omega,M fixed under theta differentiation. At fixed displayed primitive argument let the actual direct caller bounds of g0 and gt be L0 and Lt, respectively. These already include the stored original-gradient anchors and zero values of the chosen source version. Hold the independent ambient Xi fixed first.

The finite inverse recurrence gives ||D_theta h_N(p)||<= (5/2)L0 at fixed p. Hence the direct blockwise caller bounds for G_N/r are:

- S: 2(1+a)Lt;
- Z: a epsilon Lt;
- x0 and x1: omega L0 each;
- p0 and p1: a Lt+(5/2)omega L0 each;
- d and lambda: zero.

Taking the sum of these block norms is a conservative dimension-independent full bound:

    ||D_theta G_N|| <= r[(2+4a+a epsilon)Lt+7omega L0].

The exact reference has the same bound, by differentiating g0(h(p))=p in theta at fixed p; this is an analytical identity, not an inverse-Hessian VALUE call. If Xi itself has a caller map of operator bound L_Xi, add 20r L_Xi using the actual finite first bound. If fixed geometry is allowed to vary, its literal known coefficient paths must also be added. No caller bound for a small VALUE restoration error is inferred.

For one ambient occurrence, the safe original-VALUE count is 6+2N, and a requested forward or adjoint direction uses at most 6+2N original HVP sites before genuine identical-query reuse. The original K3 graph used as an input feature has its own six original VALUE calls; when evaluating the ambient lift on that graph, the six direct gradient sites coincide with those existing graph sites, but the two inverse trajectories remain complete paid chains. On an independently heated ambient input they do not coincide with the old graph, so that sharing cannot be claimed.

Captured-caller-only inverse nodes may be shared when their entire fresh dependency set is empty. Random inverse trajectories are never shared across independent complete banks. Discarded trajectories are replayed at their full cost for an adjoint. Storage is linear in N times the recorded block size for a saved trajectory; a checkpoint/replay schedule may trade storage for explicitly counted calls.

For each requested absolute inverse VALUE tolerance delta_h and actual input profile P_p, allocate half the allowance to truncation and half to oracle VALUE error:

    N >= max(0,ceil(log(5P_p/delta_h)/log 5)),
    each original VALUE error <= delta_h/5.

These leave no room for arithmetic error; allocate an additional explicit share by tightening both bounds when nonzero arithmetic errors are present. Multiplication by r omega, the common-sum norm sqrt(2), all later source readouts, and conditional moment/profile weights are applied before selecting delta_h. One can instead carry the exact residual and its actual absolute floor through later steps. Nothing is divided by an unknown actual E mark.

At fixed conditioning and a fixed target power of the heat, N grows logarithmically. The inverse primitive therefore has extra inverse-heat copy exponent exactly zero. This does not make its repeated original gradient work, Gaussian/tape dimensions, known matrix arithmetic, first sweeps, or precision free, and it does not close the remaining constrained-law or opposite-baseline requirements.
