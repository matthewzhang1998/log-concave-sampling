## 4. What remains genuinely open

The scoped return does not automatically instantiate itself on every future correction. In particular:

- A coefficient bank may cease to have the required exact product-Gaussian disintegration while preserving old physical readouts.
- Mixed old/new currents can have only one new root copy; the pure conditional root-quadratic/surplus-doubling rule does not price them.
- Old-bank derivative histories may need higher C_k and new simultaneous clock/heat estimates; each actual width and injection row remains charged.
- Smoothing error is paid at n+1/n. Restoring it to an arbitrarily high target cannot be assumed from availability of all ranks.
- Retaining an integrated private/public/root observer can destroy the old O(alpha) derivative budget.
- Every lower old mean, covariance, moving-covariance and normalization current must still be matched.
- A well-founded combined queue, a complete original-VALUE/replay complexity recurrence for that queue, and c(P)=o(P) remain unproved.

The present result removes the local all-rank active-source and fixed-rank return bottleneck at the stated boundary. It supplies a reusable native port and an explicit admission/cost record. It does not replace the remaining global induction proof with a formal power series.
